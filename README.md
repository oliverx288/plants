# Savia — pasaporte digital de plantas con NFC

Proyecto de FCT (DAW): colección física de plantas con una pegatina NFC en
cada maceta. Al acercar el móvil se abre el pasaporte digital de esa planta
— identidad, diario de crecimiento, historial de cuidados, estado actual y
mensajes con personalidad propia.

La propuesta completa del proyecto (concepto, funcionalidades,
diferenciales, mapa de páginas, modelo de datos, arquitectura, flujo NFC y
hoja de ruta MVP → fase 2) está en [`docs/propuesta-savia.md`](docs/propuesta-savia.md).

Stack: Java + Spring Boot, PostgreSQL, HTML/CSS/JS, NFC (NTAG21x), Docker.
